为什么选择 ALTRunWhy ALTRun

小巧Tiny

下载不到 1 MB，解压后约 2 MB。一个 exe 加少量资源文件，不需要 .NET、Electron 或其他运行库。 Under 1 MB to download, about 2 MB unpacked. One exe plus a few resource files — no .NET, Electron or other runtime.

快速响应Instant

输入第一个字符就显示结果；配合 Everything 毫秒级搜索全盘文件，没装时用内置索引。 Results appear as you type. With Everything, whole-disk file search takes milliseconds; otherwise a built-in index is used.

越用越懂你Smart ranking

记住每次的选择，常用的自动排第一；支持单词首字母（vsc → Visual Studio Code）和拼音首字母（wx → 微信），并高亮匹配的字。 Learns what you pick for each query. Matches word initials (vsc → Visual Studio Code) and pinyin initials, and highlights the matched characters.

多合一All in one

计算与单位换算、网页搜索、浏览器书签、剪贴板历史、文字片段自动展开、系统命令、终端，不用再装一堆小工具。 Calculator with unit conversion, web search, browser bookmarks, clipboard history, snippet expansion, system commands and a terminal.

全键盘操作Keyboard first

→ 打开操作面板，F3 直接编辑，Ctrl+1～9 快速打开；也可以双击 Ctrl 呼出。 → for the action panel, F3 to edit in place, Ctrl+1–9 to open; or double-tap Ctrl to show it.

便携与隐私Portable and private

免安装，不写注册表，不需要管理员权限，没有后台服务；数据都在 Data\ 文件夹，不收集任何数据。 No installer, no registry, no admin rights, no background service. Everything stays in the Data\ folder; no telemetry.

一键更新One-key updates

有新版本时搜索窗口里提示，按 Enter 安装，自动校验 SHA256，设置保留；也支持 Scoop。 New versions show up in the search window; press Enter to install (SHA256 verified, settings kept). Scoop is supported too.

随心定制Customizable

简体中文、繁體中文、English、日本語界面；{{THEME_COUNT}} 套内置主题，可跟随系统深浅色；主题和设置都是 JSON 文件。 English, Simplified / Traditional Chinese and Japanese interface; {{THEME_COUNT}} built-in themes that can follow the Windows light / dark mode; plain JSON settings.
