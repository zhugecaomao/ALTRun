# 对话框面板

对话框面板是 Quick Switch 的可视化操作入口。它显示在打开 / 保存对话框附近, 让你选择已打开或最近使用的文件夹, 也可以搜索文件夹和文件。

## 显示与搜索

- 默认自动显示; 对话框不在前台时隐藏。
- 空间不足时显示在对话框上方; 对话框改变宽度时面板跟随调整。
- 选择文件夹会跳转到该文件夹; 选择文件则跳转到文件所在的文件夹, 不会替你打开或保存文件。
- 搜索框先过滤当前列表, 再使用 Everything 或内置文件索引搜索。文件夹优先显示。
- 中文输入法下, 第一次按 Enter 上屏拼音, 再按一次执行跳转。

## 偏好设置

在 偏好设置 → 对话框面板 中可以设置:

- **显示面板** (ShowPanel): 开启或关闭自动显示。
- **搜索框搜索** (PanelSearch): folders 只搜文件夹 (默认), all 同时搜文件和文件夹。
- **最近文件夹数量** (RecentFolders): 默认 10, 设为 0 不显示最近文件夹。
- **面板搜索热键** (MenuHotkey): 默认 Ctrl+Shift+G; 把光标移到面板搜索框。面板未自动显示时, 该热键会临时显示面板。

更多跳转方式和窗口筛选见 [对话框跳转](Quick-Switch)。
