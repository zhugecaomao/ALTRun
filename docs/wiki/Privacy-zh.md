# 隐私与网络访问

ALTRun 不收集、不上传任何数据, 没有统计、遥测或广告。搜索、剪贴板历史、学习记录都只在本机处理和保存。

## 什么时候会联网
ALTRun 自己只在下面几种情况访问网络:

| 什么时候 | 访问哪里 | 做什么 | 怎样关掉 |
|---|---|---|---|
| 自动检查更新: 启动 1 分钟后 (离上次检查满 1 小时), 之后一直开着时每满 6 小时 | `api.github.com` | 读取最新发布的版本号, 不发送任何本机信息 | 偏好设置 → 通用 → "自动检查更新" (`General.CheckForUpdates`) |
| 一键更新: 你按了 "安装更新" 时 | `github.com` (Release 的下载文件) | 下载新版本的 zip, 先核对 GitHub 给出的 SHA256 再替换 | 不点就不会下载 |
| 货币换算 (默认关): 启动 1.5 分钟后, 离上次下载满 12 小时 | `api.frankfurter.dev` | 下载欧洲央行等公布的参考汇率, 存在 `Data\Currency.json` | 偏好设置 → 计算器 → "货币换算" (`Features.Calculator.Currency`) |
| 下载网站图标: 你在网页搜索的编辑框里点了 "下载网站图标" 时 | 网址所在的网站 | 下载这个网站的图标, 存在 `Data\Icons` | 不点就不会访问 |

除此之外, 打开网页搜索、书签、网址类的自定义命令或帮助链接时, 是交给默认浏览器打开, ALTRun 本身不访问这些网站。和 Everything、Total Commander 的通信只在本机进行 (Windows 消息), 不经过网络。

## 本机保存了什么
所有数据都在 Data 文件夹和本机的几个文件夹里, 每个文件是什么、能不能删、怎样备份见 [数据文件](Data-Files-zh)。和隐私有关的几点:
- **剪贴板历史**: 密码管理器等程序标记为 "不要记录" 的内容 (`ExcludeClipboardContentFromMonitorProcessing`、`CanIncludeInClipboardHistory = 0`) 不会记录; 偏好设置 → 剪贴板 → "不记录的程序" (默认是几个密码管理器) 里的程序复制的内容也不记录。不想在磁盘上留下历史: 把 `Features.Clipboard.Persist` 设为 0, 历史只在内存里, 退出就清空; 或者把 偏好设置 → 剪贴板 → "保存位置" 改成全部只存本机, 不跟着同步盘里的 Data 文件夹走。见 [剪贴板历史](Clipboard-zh)
- **使用统计** (`Usage.json`): 只记每天每个功能用了几次, 不记输入的内容和打开的文件
- **学习排序** (`Knowledge.json`): 记 "输入了什么 → 选了哪一项", 用来把常用的排在前面; 偏好设置 → 高级 → "重置学习排序" 清空
- **片段自动展开** 不在 Windows 的密码输入框里触发, 也可以在 偏好设置 → 文字片段 → "[不展开的窗口](Snippets-zh#不展开的窗口)" 里排除远程桌面、密码管理器等
- **调试日志** 默认不写; 偏好设置 → 高级 → "写入调试日志" 打开后写到 `%Temp%\ALTRun.log`, 用来排查问题, 记录启动和后台任务的耗时、出错的信息 (不记录在搜索框里输入的文字)。发到 issue 之前可以先看一遍内容, 见 [怎样提交调试日志](FAQ-zh#怎样提交调试日志)

## 权限
ALTRun 以普通用户权限运行, 不需要管理员权限, 不写注册表里的系统位置, 没有后台服务。只有一个例外: 勾选 偏好设置 → 键盘 → "在管理员窗口里也生效" 时, 会建一个计划任务, 以管理员身份运行一个只管 CapsLock 的小助手 (建和删时各确认一次 UAC), 见 [CapsLock 切换输入法](Hotkeys-zh#capslock-切换输入法)。
