# 文件管理器
ALTRun 用你选的文件管理器打开文件夹, 也读它当前打开的文件夹, 给 [对话框快速跳转](Quick-Switch-zh)、[对话框文件夹面板](Quick-Switch-Panel-zh)、"在此处打开终端" 和动作面板用。完整支持资源管理器、Total Commander、Directory Opus 和 Arke (0.8.0 及以上); 其他能在命令行接收文件夹路径的文件管理器可以用来打开文件夹。

## 选择文件管理器
偏好设置 → 通用 → **文件管理器**: 填程序, 后面可以带参数 (设置项 `General.FileManager`, 见 [设置文件参考](Configuration-zh))。找不到这个程序时用资源管理器打开 (日志里有记录)。

| 文件管理器 | **文件管理器** 里填 | 说明 |
|---|---|---|
| 资源管理器 | `explorer.exe` (默认) | |
| Total Commander | `C:\Apps\TotalCMD64\TOTALCMD64.exe /O /T /S` | `/O` 用已打开的窗口, `/T` 新标签页, `/S` 当前面板; `/R={path}` 总是在右面板 |
| Directory Opus | `dopus.exe` 的路径, 需要时加它自己的参数 | 文件夹加在参数后面, 或放在 `{path}` 的位置 |
| Arke | `C:\Apps\Arke\arke.exe` | 要在新标签页打开文件夹, 文件名必须是 `arke.exe` (见 [Arke](#arke)) |
| 其他 | 程序和它的参数 | 文件夹加在参数后面, 或放在 `{path}` 的位置 |

参数里的 `{path}` 指定路径放在哪里 (路径有空格时自动加引号)。程序路径有空格时要加引号, 例如 `"C:\Program Files\Arke\arke.exe"`。可以用环境变量: `%LocalAppData%\Programs\Arke\arke.exe`。

下面的 **在新标签页中打开文件夹** (`General.FolderNewTab`, 默认关) 勾上后, 文件夹在已打开窗口的新标签页里打开, 不开新窗口。

## 各文件管理器支持什么

| | 资源管理器 | Total Commander | Directory Opus | Arke 0.8.0+ | 其他 |
|---|---|---|---|---|---|
| 打开文件夹 (在文件夹上按 `Enter`、文件夹命令) | ✓ | ✓ | ✓ | ✓ | ✓ |
| 在文件管理器中显示 (`Ctrl+Enter`): 打开所在文件夹并选中 | ✓ | ✓ (ALTRun 加 `/P`) | 只打开文件夹 | 勾了 "新标签页" 时 ✓; 否则只打开文件夹 | 只打开文件夹 |
| 在新标签页中打开文件夹 | ✓ (Windows 11 22H2 及以上) | ✓ (加 `/O /T`) | 用它自己的参数 | ✓ (通过它的接口) | 用它自己的参数 |
| 对话框里按 `Ctrl+G`、自动跳转、对话框打开时跳转 | ✓ | ✓ | ✓ | ✓ | - |
| 对话框文件夹面板列出的文件夹 | 每个窗口 | 每个窗口的两个面板 | 每个窗口的当前标签页和另一侧 | 每个窗口的当前窗格和另一个窗格 | - |
| "在此处打开终端" (`TerminalHere`) | ✓ | ✓ | ✓ | ✓ | - |
| 动作面板: 复制 / 移动到 ... 当前的文件夹 | ✓ | ✓ | ✓ | ✓ | - |

从 `Ctrl+G` 往下这几行 (读当前文件夹) 和 **文件管理器** 设置无关: 文件管理器设成资源管理器时, 如果最近用的是 Total Commander 或 Arke, `Ctrl+G` 照样跳到它的文件夹。ALTRun 按窗口从前到后找到第一个文件管理器窗口, 所以用的是最近用过的那个。

ALTRun 怎么读当前文件夹 (都不经过剪贴板, 路径不会出现在 Windows 剪贴板历史里):

| 文件管理器 | 方式 | 最多等 |
|---|---|---|
| 资源管理器 | Shell 窗口列表 | - |
| Total Commander | 它的 `WM_COPYDATA` 接口 (TC 8.0 及以上) | 0.5 秒 |
| Directory Opus | 它自带的 `dopusrt.exe /info …,paths` (在正在运行的 `dopus.exe` 旁边); 结果 1.5 秒内重复使用 | 3 秒 |
| Arke | 它的 `WM_COPYDATA` 接口 (`state`), 一次请求得到所有窗口; Arke 0.9.1 起不带选中的文件, 选中几千个文件时也很快 | 0.5 秒 |

## Arke
[Arke](https://github.com/Koimsurai/Arke) 0.8.0 及以上提供给启动器和脚本用的接口, ALTRun 用的就是它, Arke 里不用做任何设置。更早的版本仍然可以打开文件夹 (`arke.exe "D:\Folder"`), 但 ALTRun 读不到它当前的文件夹。

### 一步步设置
1. 偏好设置 → 通用 → **文件管理器**: 填 `C:\Apps\Arke\arke.exe` (你的 `arke.exe` 所在的位置)
2. 想让 ALTRun 打开的文件夹出现在最近用过的 Arke 窗口的新标签页里, 勾选 **在新标签页中打开文件夹**。点 **确定**
3. 试一下:

| 你做什么 | 结果 |
|---|---|
| 在 ALTRun 里输入文件夹名, 按 `Enter` | Arke 在最近用过的窗口里开新标签页显示它, 并切到前台 |
| 在搜索结果里选中一个文件, 按 `Ctrl+Enter` (在文件管理器中显示) | Arke 在新标签页里打开文件所在的文件夹, 选中这个文件 |
| 在 Word 里按 `Ctrl+O`, 再按 `Ctrl+G` | 对话框跳到 Arke 当前窗格的文件夹 |
| 看这个对话框下面的文件夹面板 | 每个 Arke 窗口一行 "Arke" (当前窗格), 分屏时还有一行 "Arke (另一侧)" |
| 加一个 [自定义热键](Hotkeys-zh), 动作 `TerminalHere`, 窗口填 `ahk_class ArkeWindow` (默认的 `Ctrl+Alt+T` 只用于资源管理器), 在 Arke 里按它 | 在 Arke 当前的文件夹打开终端 |

### 哪个文件夹算数
- 每个窗口只看 **当前标签页**: 当前窗格, 分屏时另一个窗格也列在面板里。其他标签页不列出
- 开着几个 Arke 窗口: `Ctrl+G` 用最近用过的那个; 面板从前到后全部列出
- 只有文件夹、盘符 (`D:\`) 和网络共享 (`\\server\share`) 算数。主页、搜索结果、回收站、SFTP / WebDAV 位置和设置之类的页面不算文件夹: `Ctrl+G` 跳不过去 (提示没有打开的文件管理器窗口), 面板里也没有这个窗格的行
- 勾了 **在新标签页中打开文件夹** 时, ALTRun 先找显示 ALTRun 之前在前台的 Arke 窗口, 没有就用最近用过的 Arke 窗口。没有打开的 Arke 窗口 (只有通知区域图标)、Arke 低于 0.8.0 或者没有回应时, 和没勾一样运行 `arke.exe "文件夹"` (Arke 的单窗口模式下也是开新标签页)
- 没勾 **在新标签页中打开文件夹**: 运行 `arke.exe "文件夹"`; 在文件管理器中显示只打开所在的文件夹, 不选中

### 限制
- Arke **以管理员身份运行**而 ALTRun 不是: Windows 不把消息传给权限更高的程序, ALTRun 读不到 Arke 的文件夹 (Arke 在其他文件管理器窗口前面时, `Ctrl+G` 提示没有打开的文件管理器窗口), 打开文件夹改用 `arke.exe "文件夹"`。两个程序用同样的权限运行即可
- ALTRun 只读 Arke 的状态、请它打开文件夹, 不会通过 Arke 改动文件 (Arke 的接口也不允许)
- 打开 [日志](Configuration-zh) 后, 日志里有每次读取用的时间 (`Perf: Arke state … ms, … windows`), 以及没能通过接口打开文件夹的原因 (`Arke: didn't open …`)
