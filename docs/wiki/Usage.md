# 搜索与快捷键

## 搜索窗口
按 `Alt+Space` (可在 偏好设置 → 通用 修改, 也可以再设一个 "第二个呼出热键") 呼出, 输入即搜。每行显示图标、标题和一行说明 (路径、参数或类型), 右侧是 `Ctrl+数字` 快捷键。窗口失去焦点时自动隐藏。

## 输入语法
| 输入 | 结果 |
|---|---|
| 任意文字 | 应用、自定义命令、片段、系统命令、Windows 工具 |
| `空格` 再输入 (搜索框为空时按空格) | 只搜索文件和文件夹, 输入框显示 "搜索文件..."; 输入框为空时 `Backspace` 返回 |
| `12*(3+4)` 或 `=2^10` | 计算器, `Enter` 复制结果 |
| `'报告` / `open 报告` / `find 报告` | 只搜索文件和文件夹, 见 [文件搜索](File-Search) |
| `g xxx` `bing xxx` `bd xxx` `gh xxx` `wiki xxx` `yt xxx` `tb xxx` `jd xxx` `tr xxx` | 网页搜索: Google / Bing / 百度 / GitHub / 维基百科 / YouTube / 淘宝 / 京东 / Google 翻译 |
| `>命令` | 在终端里运行, 例如 `>ipconfig /all` |
| `clip` / `clip xxx` | 剪贴板历史 (全部 / 过滤) |
| `snip` / `snip xxx` | 只搜索文字片段 |
| `;关键字` (在任何程序里) | 片段自动展开, 见 [自定义命令与片段](Commands-and-Snippets) |

关键字后面加了空格 (例如 `clip `、`g xxx`、`'xxx`、`>xxx`), 就只显示这个功能的结果。没有任何结果时, 显示兜底项: 用 Google 搜索、搜索文件、用 Bing 搜索 (可在 `Features.WebSearch.Fallbacks` 修改)。

### 怎样匹配
不区分大小写, 按下面的顺序打分:

| 规则 | 例子 |
|---|---|
| 完全相同 | `notepad` → Notepad |
| 开头相同 | `note` → Notepad |
| 某个单词的开头 | `code` → Visual Studio Code |
| 单词首字母 | `vsc` → Visual Studio Code |
| 拼音首字母 | `wx` → 微信 |
| 包含 | `pad` → Notepad |
| 多个关键词 | `st co` → Visual Studio Code |
| 按顺序出现的字母 (至少 3 个, 首字母相同) | `ntpd` → Notepad |

![拼音首字母: jsb → 记事本](https://raw.githubusercontent.com/zhugecaomao/ALTRun/main/docs/images/screenshots/pinyin.png)

自定义命令还会按目标的文件夹名 / 文件名匹配, 例如 Target 是 `Q:\Projects\PT1931 - 24 NIR` 时输入 `nir` 也能找到。

### 学习排序
ALTRun 记住 "输入了什么 → 最后选了哪一项": 输入 `no` 选过记事本, 下次输入 `no` 或 `not` 时记事本排第一; 常用的项目整体也会靠前。搜索框为空时按 `↑` 调出最近的搜索。学习记录保存在 `Data\Knowledge.json`, 可以在 偏好设置 → 高级 里重置。

## 快捷键
| 按键 | 作用 |
|---|---|
| `Enter` | 执行选中项 (打开文件 / 程序 / 网址, 复制计算结果, 粘贴片段...) |
| `Ctrl+Enter` | 文件 / 文件夹: 在文件管理器中显示; 文字: 粘贴到前台窗口 |
| `Alt+Enter` | 复制路径 / 网址 / 文字 |
| `Ctrl+1` ~ `Ctrl+9` | 直接执行可见的第 N 行 |
| `↑` `↓` `PgUp` `PgDn` `Ctrl+P` `Ctrl+N` | 移动选择 |
| `↑` (搜索框为空时) | 调出最近的搜索 |
| `Tab` | 自动补全 |
| `空格` (搜索框为空时) | 进入文件搜索模式; `Backspace` 返回 |
| `空格` (已输入文字) | 打开 偏好设置 → 通用 → "按空格执行选中项" 后: 执行选中项, `Shift+空格` 输入空格 (多个关键词时用) |
| `→` (光标在末尾) | 打开操作面板; `←` / `Esc` 返回 |
| `F3` | 编辑选中项, 见下文 |
| `Ctrl+Del` (光标在末尾) | 删除选中项, 见下文 |
| `Ctrl+C` | 复制选中项 (输入框里选中了文字时照常复制文字) |
| `Ctrl+L` | 大字显示 |
| `Ctrl+Backspace` | 删除前一个词 |
| `F2` / `Ctrl+,` | 偏好设置 |
| `F4` | 用记事本编辑 ALTRun.json (保存后自动重新载入) |
| `Esc` | 关闭操作面板 / 隐藏窗口 |
| `Ctrl+Alt+C` (全局) | 剪贴板历史 |

鼠标: 单击选择, 双击执行, 滚轮移动选择, 右键弹出操作菜单。

## 操作面板
选中一项按 `→` (或鼠标右键) 列出它的全部操作, 可以继续输入文字过滤:

![操作面板](https://raw.githubusercontent.com/zhugecaomao/ALTRun/main/docs/images/screenshots/actions.png)

| 结果类型 | 操作 |
|---|---|
| 程序 / 文件 | 打开、以管理员身份运行 (exe / lnk / bat...)、在文件管理器中显示、复制路径、复制名称、在此处打开终端、属性 |
| 文件夹 | 打开、在此处打开终端、在文件管理器中显示、复制路径、属性 |
| 网址 | 打开、复制网址 |
| 文字 | 复制、粘贴到前台窗口 |
| 全部 | 编辑... / 添加到自定义命令... (`F3`)、删除 (`Ctrl+Del`)、大字显示 (`Ctrl+L`) |

## 在结果里编辑和删除
| 选中的是 | `F3` | `Ctrl+Del` |
|---|---|---|
| 自定义命令 / 文字片段 / 搜索引擎 | 打开编辑窗口, 保存后回到原来的搜索 | 确认后删除 |
| 剪贴板历史 | 保存为文字片段 | 从历史中删除 |
| 应用 | 添加为自定义命令 (可以再加关键字) | 从搜索结果中删除 (不卸载程序), 可在 偏好设置 → 应用搜索 → "已删除的应用" 里恢复 |
| 文件 / 文件夹 / 网址 | 添加为自定义命令 | - |
| 没有结果 | 用输入的文字新建一条自定义命令 | - |
