# 5 分钟上手

## 1. 安装和启动
从 [GitHub Releases](https://github.com/zhugecaomao/ALTRun/releases/latest) 下载 `ALTRun_v<版本>.zip`, 解压到任意文件夹 (例如 `D:\Tools\ALTRun`), 运行 `ALTRun.exe`。不需要安装, 也不需要管理员权限; 用 Scoop / winget 安装见 [安装与升级](Installation-zh)。

第一次运行会弹出搜索窗口, 托盘里出现 ALTRun 的图标。默认开机自动启动 (偏好设置 → 通用 可以关掉)。

## 2. 呼出搜索窗口
按 `Alt+Space` (或者 `Alt+R`)。再按一次、按 `Esc` 或点别处就隐藏。热键在 偏好设置 → 通用 里改; 也可以设成双击 `Ctrl` 呼出。

## 3. 打开程序和文件
- 输入程序名的一部分, 例如 `note` 找记事本; 也可以输单词首字母 (`vsc` → Visual Studio Code) 或拼音首字母 (`wx` → 微信)
- `Enter` 打开选中的一项, `↑` `↓` 选择, `Ctrl+1` ~ `Ctrl+9` 直接打开第几项
- 选中后按 `→` (或鼠标右键) 打开操作面板: 以管理员身份运行、在文件管理器中显示、复制路径...
- 以 `'` 开头只搜文件和文件夹, 例如 `'报告`; 装了 [Everything](https://www.voidtools.com/) 时搜全盘, 否则搜桌面、文档、下载, 见 [文件搜索](File-Search-zh)

选过的项目会记下来, 下次输入同样的字时排在最前面。

## 4. 试几个常用功能
| 输入 | 结果 |
|---|---|
| `12*(3+4)` | 计算, `Enter` 复制结果 ([计算器](Calculator-zh)) |
| `10 km in mi` | 单位换算 |
| `g 天气` | 用 Google 搜索 ([网页搜索](Usage-zh#输入语法)) |
| `clip` 或 `Ctrl+Alt+C` | 剪贴板历史 ([剪贴板历史](Clipboard-zh)) |
| `lock` | 锁屏等系统命令 ([系统命令](System-Commands-zh#系统命令)) |
| `>ipconfig` | 在终端里运行命令 |
| `?` | 速查表: 所有输入语法和快捷键 |

## 5. 加一个自己的命令
常用的文件夹、文件、网址加成自定义命令, 以后输入名字或关键字就能打开:
- 资源管理器里右键 → 发送到 → ALTRun, 改好名称, 按 `Enter`
- 或者 偏好设置 → 自定义命令 → 添加

常用的文字 (签名、地址) 存成文字片段, 在任何程序里输入 `;关键字` 自动替换, 见 [文字片段](Snippets-zh)。

## 6. 偏好设置
托盘图标右键 → 偏好设置, 或者在搜索窗口里按 `F2` / `Ctrl+,`。每一页按 `F1` (或点 帮助) 打开那一页的说明。外观里可以选 22 套主题和显示密度, 见 [主题](Themes-zh)。
