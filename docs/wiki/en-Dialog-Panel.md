# Dialog Panel

The Dialog Panel is the visual entry point for Quick Switch. It appears next to Open / Save dialogs so you can pick an open or recently used folder, or search for folders and files.

## Display and search

- Shown automatically by default; hidden when the dialog is not in the foreground.
- Appears above the dialog when there is not enough room below, and follows the dialog's width when resized.
- Selecting a folder jumps to it. Selecting a file jumps to its containing folder; it does not open or save the file for you.
- The search box filters the current list first, then searches with Everything or the built-in file index. Folders are shown first.
- With a Chinese input method, press Enter once to commit pinyin and again to jump.

## Preferences

In Preferences → Dialog Panel:

- **Show panel** (ShowPanel): enable or disable automatic display.
- **Search box finds** (PanelSearch): folders searches folders only (default); all searches both files and folders.
- **Recent folders** (RecentFolders): 10 by default; set to 0 to hide recent folders.
- **Panel search hotkey** (MenuHotkey): Ctrl+Shift+G by default; focuses the panel search box. If the panel is hidden, the hotkey shows it temporarily.

For navigation hotkeys and window filters, see [Quick Switch](Quick-Switch).
