# 窗口切换

输入窗口标题或程序名, `Enter` 切换到这个已经打开的窗口 (最小化的先还原), 和 PowerToys Run 的 Window Walker、Raycast 的 Switch Windows 一样。

## 找窗口
| 输入 | 得到 |
|---|---|
| `w ` (`w` 加空格) | 所有窗口, 按前后顺序 (最近用过的在前) |
| `w excel` | Excel 的窗口, 以及标题里有 "excel" 的窗口 |
| `w 报价` | 标题里有 "报价" 的窗口, 例如 `报价 2026-118.xlsx - Excel` |
| `w bjb` | 也能用标题的拼音首字母: 标题是 `笔记本` 的窗口 |
| `报价` (不加关键字) | 先是应用和命令, 后面最多 3 个标题匹配得好的窗口 (输入 2 个字以上) |

窗口按标题、程序名 (`EXCEL.EXE` 就是 `excel`) 和标题的拼音首字母匹配, 规则和其他结果一样 ([匹配规则](Usage-zh#怎样匹配))。每个窗口各是一个结果: Word 打开三个文档就是三个结果, 标题下面写着 "WINWORD.EXE - 切换到这个窗口"。

## 切换和关闭
- `Enter` (或点一下) 切换到这个窗口, 最小化的先还原
- 在窗口上按 `→`: **关闭窗口**。和点它的 × 一样正常关闭, 有没保存的内容时程序照样会先问
- 窗口在这之间已经关掉时, 会提示 "这个窗口已经关闭了"

## 列出哪些窗口
和任务栏上的一样:

| 列出 | 不列出 |
|---|---|
| 当前虚拟桌面上可见、有标题的窗口 | 隐藏的窗口、没有标题的窗口、工具窗口 (浮动面板)、属于别的窗口的对话框、别的虚拟桌面上的窗口、挂起的商店应用、桌面、ALTRun 自己的窗口 |

每次搜索都重新读窗口列表 (1 秒内连续输入时沿用), 刚打开的窗口也能搜到。窗口不会被记进 [最近使用](Recent-zh), 也不参与学习排序: 窗口只在开着时存在。

## 设置
偏好设置 → 功能: "窗口切换" 打开或关闭整个功能; 下面的 "功能选项" 里, "普通搜索里也显示" 和 "关键字" 对应:

| 设置 | 默认 | 说明 |
|---|---|---|
| `Features.Windows.Enabled` | `1` | 是否启用窗口切换 |
| `Features.Windows.Keyword` | `w` | 只搜窗口的关键字 |
| `Features.Windows.InDefaultResults` | `1` | 直接输入时也显示标题匹配得好的窗口 |

不想让窗口出现在普通搜索结果里: 关掉 "普通搜索里也显示", 要找窗口时用 `w`。想换关键字 (例如 `w` 已经是自己的关键字, 改成 `ww`): 改 "关键字"。
