# 截图用的文档图标

`text.ico`、`spreadsheet.ico`、`presentation.ico` 来自 [LibreOffice](https://github.com/LibreOffice/core/tree/master/sysui/desktop/icons) (`sysui/desktop/icons`), 按 [MPL-2.0](https://www.mozilla.org/MPL/2.0/) 许可使用, 未作修改 (只去掉了一些尺寸)。

GitHub Actions 的 Screenshots 工作流截图前把 `.docx` / `.xlsx` / `.pptx` 等关联到这些图标 (只在虚拟机上、只写当前用户的注册表), 截图里的文档就有图标, 不用安装 Office。ALTRun 本身不使用这些图标。
